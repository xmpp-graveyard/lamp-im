Lamp IM
======

Lamp IM was a prototype of a Windows XMPP/Jabber client written in Delphi and developed around the years 2010-2011.

The author's nickname is `Narkoz`.

This repository represents a copy of the zip file provided by the developer on his sourceforge page.

Unfortunately, the source code for the shipped plugins is not available.

The software is provided as-is, for preservation and education purposes.

----

### Dependencies

This project requires:
* AlphaControls / AlphaSkins v7.29 Stable from 16.01.2011 (can be found in downloads).
* TJabberClient (can be found in the source tree).
